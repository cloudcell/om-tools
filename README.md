# OM Tools

OM Tools provides the VS Code/VSCodium user interface and development tools for the [OM Core](https://github.com/cloudcell/om-core) multidimensional modeling engine. The extension connects to an OM Core runtime rather than reimplementing its calculation engine.

## Development

```bash
npm install
npm run build
npm run compile
npm test
```

The runtime configuration and integration notes are in [AGENTS.md](AGENTS.md). To use the extension, a compatible OM Core runtime is required.
